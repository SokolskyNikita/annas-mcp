annas-mcp Books and research for agents

Search Anna's Archive for books and OpenAlex for papers and dissertations, then download or read the selected work. Run annas-cli in your terminal or connect annas-mcp to Claude, Cursor, Codex and other AI clients.

What it does

ToolWhat it does
book_searchFinds books, textbooks, manuals and standards by title, author or topic, filtered by format, language, source or year
article_searchFinds papers and dissertations by title, author, topic, DOI or OpenAlex work ID
article_detailsInspects abstracts, identifiers, copies, versions, licenses and access links
article_readReads bounded passages of structured full text with provenance and continuation
metadata_searchSearches library catalogs such as Open Library, WorldCat and ISBNdb for editions and ISBNs
book_detailsShows a result's ISBNs and other identifiers, edition, description and reported file problems
account_statusShows Anna’s membership and allowance, or OpenAlex usage and rate limits
book_downloadDownloads a book using the hash from a search result
article_downloadDownloads a paper or dissertation by DOI, OpenAlex work ID or archive hash

Known DOI and OpenAlex IDs can go straight to download. For titles or ambiguous citations, search and select the right authors and year first. Available routes include hosted OpenAlex PDFs, direct open copies and configured Anna’s Archive fallback. Completed files can be verified and reused.

Setup

You need Node.js 18 or newer and an OpenAlex API key, an Anna’s Archive membership, or both. OpenAlex supports research access with its own account allowance. Archive search needs Lucky Librarian or higher, and archive downloads need any paid tier. Configure OPENALEX_API_KEY for research or ANNAS_SECRET_KEY for archive access.

CLI setup

npm install -g annas-mcp
export OPENALEX_API_KEY="your-openalex-key"

annas-cli --help
annas-cli article-search "graph algorithms" --work-type dissertation

In PowerShell, set the key with $env:OPENALEX_API_KEY="your-openalex-key". Installation adds both commands automatically: annas-cli shows help with no arguments, while annas-mcp starts MCP. Both support the same operations and settings. No MCP client is needed for the CLI.

For one-off commands, use npx -y --package=annas-mcp annas-cli followed by the command and its options. See the README for configuration and all CLI commands.

MCP setup

To use the tools from an AI client, add the server using the instructions for your client below.

Claude Code

claude mcp add annas-mcp \
  --env OPENALEX_API_KEY=your-openalex-key \
  -- npx -y annas-mcp

Claude Desktop

Download annas-mcp.mcpb and open it. Claude Desktop offers optional OpenAlex and Anna’s Archive keys and a download folder.

Cursor, or Claude Desktop by hand

{
  "mcpServers": {
    "annas-mcp": {
      "command": "npx",
      "args": ["-y", "annas-mcp"],
      "env": {
        "OPENALEX_API_KEY": "your-openalex-key"
      }
    }
  }
}

Codex

[mcp_servers.annas-mcp]
command = "npx"
args = ["-y", "annas-mcp"]

[mcp_servers.annas-mcp.env]
OPENALEX_API_KEY = "your-openalex-key"

Add ANNAS_SECRET_KEY alongside the OpenAlex key for archive fallback and book access. Desktop clients may need explicit keys because they do not inherit shell exports. Then ask "Download the AlphaFold paper, DOI 10.1038/s41586-021-03819-2" or "Find dissertations on graph algorithms." Files are saved to an annas-archive folder in your home folder; set ANNAS_DOWNLOAD_PATH to use another one. Docker, the command line and every option are in the README.

Use it from Go

The public anna package supports archive operations, and papers coordinates research search, access and reading across providers. It requires Go 1.26 or newer and shares the project's release versions.

go get github.com/SokolskyNikita/annas-mcp/anna@v0.8.0

See the SDK guide and examples for explicit configuration, timeouts, error handling and concurrent use.
